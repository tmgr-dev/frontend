В этом уроке создаём задачи, смотрим их и двигаем по доске, не открывая браузер. Нужен `tmgr`, в который вы уже вошли: см. [1. Установка и вход](/docs/ru/cli/install-and-sign-in).

## Новая задача {#add}

```sh
tmgr add "Write release notes" -p <project>
```

Название пишется в кавычках, код проекта передаётся флагом `-p` (или `--project`). В ответ `tmgr` выводит ключ новой задачи и ссылку на неё в веб-приложении.

Статус задаётся флагом `-s` (или `--status`) с названием статуса. Без него задача получит статус воркспейса по умолчанию.

Описание можно взять из файла флагом `--desc-file`:

```sh
tmgr add "Write release notes" -p <project> --desc-file notes.md
```

## Список задач и одна задача {#list}

```sh
tmgr task list
```

Команда показывает задачи текущего воркспейса: ключ, статус и название. Список можно отфильтровать:

- `--project <project>` (или `-p`): только один проект.
- `--status-type <type>`: только один тип статуса — `default`, `active`, `completed`, `hidden` или `archived`.
- `--limit <n>`: сколько задач показать (по умолчанию 50). `--cursor` открывает следующую страницу.

```sh
tmgr task list --project <project> --status-type active
```

Одну задачу открывают по ключу:

```sh
tmgr task show TM-123
```

## Доска {#board}

```sh
tmgr board
```

Канбан-доска прямо в терминале.

- Стрелки или `h` `j` `k` `l` перемещают по колонкам и карточкам.
- Enter открывает и закрывает подробности карточки.
- Shift+L переносит карточку в следующий статус, Shift+H — в предыдущий.
- `s` запускает таймер по карточке, Shift+S останавливает его.
- `c` добавляет комментарий.
- `/` ищет, `?` показывает подсказку, `q` закрывает доску.

`--project <project>` показывает один проект, `--mine` — только ваши задачи, а `--ascii` рисует доску простыми символами ASCII.

```sh
tmgr board --project <project> --mine
```

## JSON для скриптов {#json}

С флагом `--json` команды выдают машиночитаемый ответ со стабильной схемой `tmgr.v1`. Сами данные лежат в `.data`. Например, выведем ключи задач из Backlog через `jq`:

```sh
tmgr task list --json | jq -r '.data.items[] | select(.status.name=="Backlog") | .ref'
```

Схемы лежат в [исходном коде tmgr](https://github.com/tmgr-dev/frontend/tree/master/crates/tmgr-cli/schemas/tmgr.v1).

## Задача из стандартного ввода {#stdin}

Если вместо названия передать `-`, `add` прочитает задачу из стандартного ввода: первая строка станет названием, остальное — описанием.

```sh
echo "Fix broken links on /blog" | tmgr add - -p <project>
```
