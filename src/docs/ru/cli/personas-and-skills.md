В этом уроке: персоны и скиллы (навыки), как положить скилл в общую библиотеку и выдать его персоне.

## Текст видео {#transcript}

Урок восьмой: персоны и скиллы. Персона — это ИИ-сотрудник в TMGR со своей ролью и инструкциями, а скиллы — общие рецепты, которые можно выдать любой персоне.

### Новый скилл {#t-put}

Скилл — это обычный маркдаун-файл. В шапке: короткое имя, заголовок, когда его применять и какие шаги он включает. Ниже — сама инструкция.

```sh
cat skills/release-notes.md
tmgr skills put release-notes --file skills/release-notes.md
```

`tmgr skills put` загружает файл в общую библиотеку, а каждое изменение становится новой версией.

### Привязка к персоне {#t-attach}

`tmgr skills attach` выдаёт скилл персоне по её идентификатору из веба.

```sh
tmgr skills attach <persona-id> release-notes
```

Теперь список показывает, у каких персон он есть.

```sh
tmgr skills list
```

Агент, работающий от имени персоны, получает её инструкции и все её скиллы.

### Просмотр {#t-show}

Это показывает скилл целиком, вместе с версией и персонами.

```sh
tmgr skills show release-notes
```

Обновили файл — снова `tmgr skills put`, и все персоны получат новую версию. `tmgr skills detach` и `tmgr skills delete` снимают скилл с персоны или удаляют совсем.
