В этом уроке вы выводите текущую задачу и таймер в приглашение шелла, в tmux и в статус-строку Claude Code.

## Текст видео {#transcript}

Урок шестой: `tmgr` в приглашении шелла, в tmux и в статус-строке Claude Code. Текущая задача и таймер всегда перед глазами.

### Сниппет {#t-snippet}

Команда `init` печатает сниппет для вашего шелла: bash, zsh или fish.

```sh
tmgr init bash
```

С флагом `--install` она сама добавит его в конфиг: покажет изменения, спросит подтверждение и сохранит резервную копию.

```sh
tmgr init bash --install
source ~/.bashrc
```

### Приглашение {#t-prompt}

Теперь, когда задача запущена, в приглашении видно её номер и сколько идёт таймер.

```sh
tmgr start TM-123 --no-branch
tmgr status
```

Строка берётся из локального файла состояния, без запросов к серверу, так что шелл не тормозит.

### tmux и Claude Code {#t-more}

То же самое есть для tmux, Starship и статус-строки Claude Code: `init tmux` и `init claude` выдают готовые фрагменты конфига.

```sh
tmgr init tmux
tmgr init claude
```

### Пауза {#t-stop}

`stop` останавливает таймер, и приглашение показывает, что задача на паузе.

```sh
tmgr stop
```
