В этом уроке: как агенты отчитываются о работе над задачами и как вы читаете эти отчёты.

## Текст видео {#transcript}

Урок девятый: отчёты агентов. Вы видите, какой агент работал над задачей, сколько, с какими коммитами и тестами.
### Хуки {#t-hooks}

Эта команда добавляет хуки TMGR в настройки Claude Code: уведомления, когда агент ждёт вас, и привязку коммитов к его запуску.

```sh
tmgr hook install claude
```

Команда покажет изменения и спросит подтверждение; ответьте `y`. Для Codex — `tmgr hook install codex`.

### Отчёт о работе {#t-report}

Сам отчёт — три команды. `tmgr agent start` открывает запуск на задаче: агент, модель и ветка.

```sh
tmgr agent start TM-123 --agent claude-code --model claude-sonnet-5-5
```

`tmgr agent update` добавляет коммиты, пулл-реквест и результаты тестов, и служит пульсом: запуск без обновлений сорок пять минут считается брошенным.

```sh
tmgr agent update --commit "$(git log -1 --format='%h %s')" --tests-passed 12 --tests-failed 0
```

`tmgr agent finish` закрывает запуск со статусом и итогом.

```sh
tmgr agent finish --status succeeded --summary "Redirect loop fixed, all tests pass"
```

Агенты делают то же самое через MCP-сервер задач.

### Журнал {#t-log}

`tmgr log` показывает запуски агентов по воркспейсу или по задаче: кто работал, сколько, ветка, коммиты, тесты и итог.

```sh
tmgr log --task TM-123
```

С флагом `--follow` журнал обновляется в реальном времени.
