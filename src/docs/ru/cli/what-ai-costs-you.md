В этом уроке вы узнаете, сколько стоят ваши ИИ-агенты: токены, стоимость и лимиты, посчитанные по локальным логам Claude Code и Codex.

## Текст видео {#transcript}

Урок седьмой: сколько стоят ИИ-агенты. `tmgr` читает локальные логи Claude Code и Codex и считает токены, стоимость и лимиты. В демо — сгенерированные логи.

### Согласие {#t-consent}

Сначала разрешение: логи читаются только с вашего согласия.

```sh
tmgr usage consent allow
```

Хранятся счётчики токенов, модели, время и ветки, но никогда не текст запросов и ответов. С устройства ничего не уходит, пока вы сами не включите синхронизацию.

### За неделю {#t-week}

Использование за неделю: стоимость по моделям, токены на вход и выход, чтение и запись кэша.

```sh
tmgr usage --week
```

Это эквивалент цены API по прайс-листу, а не ваш счёт по подписке.

### Разбивка {#t-by}

Флаг `--by` группирует по дням, проектам, веткам или задачам.

```sh
tmgr usage --week --by day
```

По веткам сразу видно, какая фича обошлась дороже всего.

```sh
tmgr usage --week --by branch
```

А привязка к задачам появляется, когда агенты работают через команды `run` или `agent start`.

### Лимиты {#t-limits}

`tmgr usage limits` показывает окна лимитов, процент использования и время до сброса.

```sh
tmgr usage limits
```

Для Claude Code данные даёт хук статус-лайна. `tmgr usage statusline install` показывает, что изменится в настройках Claude Code; с флагом `--install` изменение применяется:

```sh
tmgr usage statusline install --install
```
