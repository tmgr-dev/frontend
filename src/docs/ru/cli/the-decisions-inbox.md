В этом уроке агент задаёт вопрос, вы отвечаете на него во входящих решениях, и ответ возвращается агенту.

## Текст видео {#transcript}

Урок пятый: входящие решения. Агент задаёт вопрос, вы отвечаете в одном месте, и ответ возвращается агенту.

### Вопрос {#t-ask}

Команда `ask` отправляет карточку с вопросом: заголовок, контекст, варианты и рекомендованный вариант. Флаг `--wait` блокирует выполнение, пока вы не ответите, так что агент ждёт решения, а не гадает. Флаг `--key` даёт вопросу имя: повторная отправка обновит ту же карточку.

```sh
tmgr ask --title "Which database for the blog?" \
  --context "Full-text search, about 10k posts" \
  --option SQLite --option Postgres --recommended 2 \
  --key blog-db --wait
```

### Окно «Решения» {#t-inbox}

Карточки собираются в окне «Решения» десктопного приложения для macOS и Linux. Там видны контекст, варианты, рекомендация агента и изменения на ревью. Отвечаете цифрой, Enter или своим текстом.

### Ответ {#t-answer}

Ответ сразу приходит в терминал, и агент продолжает работу.

### Прошлые ответы {#t-answers}

`decisions answers` находит уже данные ответы, так что агент может проверить, не решали ли вы это раньше. `--key` отбирает карточки, ключ которых начинается с указанного префикса.

```sh
tmgr decisions answers --key blog-
```

А для самих агентов есть MCP-сервер: команда `tmgr mcp` даёт им инструменты, чтобы задать вам вопрос, найти прошлые ответы и прислать уведомление.

```sh
tmgr mcp --help
```
