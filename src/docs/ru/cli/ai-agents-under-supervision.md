В этом уроке вы запускаете агента в песочнице, смотрите, что он делает, и откатываете его изменения.

## Текст видео {#transcript}

Урок четвёртый: ИИ-агенты под присмотром. Запускаем агента в песочнице, смотрим, что он делает, и откатываем его изменения. Для наглядности вместо настоящего агента в видео простой скрипт; с Claude Code и Codex всё работает так же.

### Запуск {#t-run}

Команда `run` запускает агента в песочнице: у него своя домашняя папка и только нужные переменные окружения. Флаг `--worktree` даёт агенту отдельную копию проекта на своей ветке, так что два агента никогда не пишут в одни файлы, а флаг `--checkpoints` сохраняет папку после каждого хода.

```sh
tmgr run --agent claude-code --worktree --checkpoints --name site-footer
```

Сразу открывается живой экран сессии: пишем задачу и смотрим, как агент правит файлы. Ctrl+] и затем D отключают экран, а агент продолжает работать.

### Наблюдение {#t-watch}

Команда `agents` показывает все сессии и что с ними: работает, ждёт ответа или заблокирован.

```sh
tmgr agents
```

`peek` выводит текущий экран сессии простым текстом, а `attach` снова открывает живой вид.

```sh
tmgr peek site-footer
```

### Откат {#t-restore}

Каждый ход агента — отдельная точка сохранения. `checkpoints list` показывает их.

```sh
tmgr checkpoints list site-footer
```

`checkpoints diff` показывает, что изменилось на конкретном шаге.

```sh
tmgr checkpoints diff site-footer 3
```

`checkpoints restore` возвращает папку к нужному состоянию и просит подтверждение. Текущее состояние при этом тоже сохраняется, так что откат можно отменить.

```sh
tmgr checkpoints restore site-footer 2
```

А `halt` останавливает сессию.

```sh
tmgr halt site-footer
```
