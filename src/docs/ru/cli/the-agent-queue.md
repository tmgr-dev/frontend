В этом уроке вы настроите очередь агентов: задачи, назначенные на персону и одобренные вами, запускаются на вашей машине, а результат приходит пулл-реквестом.

## Текст видео {#transcript}

Урок десятый: очередь агентов. Задачи, назначенные на персону и одобренные вами, сами запускаются на вашей машине, а результат приходит пулл-реквестом. Агент в демо — простой скрипт, который играет роль настоящего агента.

### В вебе {#t-web}

Всё начинается в вебе, в видео это показано в веб-интерфейсе. В модулях воркспейса включаем запуски агентов (Agent runs), назначаем задачу на персону и подтверждаем её для запуска агентом (Confirm for agent runs). Подтверждение — это подпись над точным текстом задачи: если кто-то его изменит, подпись слетит.

### Доверие машине {#t-allow}

На своей машине разрешаем воркспейс:

```sh
tmgr runner allow <workspace>
```

`tmgr` показывает ключи, которыми подписаны одобрения, и закрепляет их, так что задача с чужой подписью не запустится. Подтвердите, введя код воркспейса.

### Репозиторий {#t-bind}

`tmgr runner bind` связывает проект с вашей локальной копией репозитория из настроек проекта.

```sh
tmgr runner bind <workspace>:<project> ~/acme-site
```

Подтверждаем кодом проекта.

### Правило {#t-rule}

Правило очереди задаёт, что можно запускать: воркспейс, проект, персону, профиль агента, папку и сколько агентов одновременно. Облачное правило запускает только подписанные вами задачи.

```sh
tmgr queue rules add my-site --workspace <workspace> --persona Builder \
  --profile claude-code --repo ~/acme-site --project <project> --auto --max-concurrent 2
```

При добавлении правила нужно ввести `I AGREE`.

### Очередь {#t-queue}

Это включает очередь в фоне; здесь тоже нужно ввести `I AGREE`.

```sh
tmgr queue enable
```

Очередь сама находит одобренную задачу, делает для неё отдельную копию проекта и запускает агента в песочнице. В видео это сразу запускает один проход.

```sh
tmgr queue run-once
```

Это показывает сессию: агент уже отработал.

```sh
tmgr agents
```

### Результат {#t-result}

Это показывает, что сделал агент. Команда принимает id или имя сессии.

```sh
tmgr peek <session>
```

Когда агент закончил, очередь пушит ветку и открывает пулл-реквест, который ждёт вашего ревью. Это выключает очередь.

```sh
tmgr queue disable
```

А команда `tmgr autopilot` строит на этой очереди целые команды агентов во главе с Claude Code.
