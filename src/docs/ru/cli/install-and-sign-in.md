`tmgr` — командная строка для таск-менеджера TMGR. В этом уроке вы установите её, войдёте в аккаунт, выберете воркспейс и осмотритесь.

## Установка {#install}

`tmgr` ставится на macOS или Linux одной командой:

```sh
curl -fsSL https://tmgr.dev/install.sh | sh
```

Скрипт скачивает подписанный релиз под вашу систему, проверяет его и кладёт программу в `~/.local/bin` в домашней папке. Права администратора и sudo не нужны. Если этой папки ещё нет в `PATH`, скрипт подскажет её добавить.

Подпись проверяется через `minisign`, если он установлен. Без `minisign` скрипт предупредит об этом и сверит архив с контрольной суммой из манифеста релиза, скачанного по HTTPS. При неверной подписи или контрольной сумме установка всегда останавливается.

На Windows используйте WSL2 и выполните ту же команду внутри него.

## Вход {#sign-in}

```sh
tmgr login
```

Пароль в терминал вводить не нужно. `tmgr login` выводит ссылку для входа и одноразовый код и открывает ссылку в браузере. Убедитесь, что в браузере тот же код, подтвердите вход, и терминал получит доступ.

Код действует ограниченное время: сколько минут, терминал пишет рядом с кодом. Если на этой машине браузер не открыть (например, вы зашли по SSH), откройте ссылку на другом устройстве. Флаг `--no-browser` не открывает браузер:

```sh
tmgr login --no-browser
```

## Кто вошёл {#whoami}

```sh
tmgr whoami
```

Команда показывает, кто вошёл и на каком сервере, права и срок действия токена и где он хранится: в системной связке ключей или хранилище учётных данных, а если его нет, в закрытом файле.

## Воркспейсы {#workspaces}

Задачи живут в воркспейсах. Список воркспейсов:

```sh
tmgr ws list
```

Звёздочка `*` отмечает текущий. Переключиться на другой можно по его коду:

```sh
tmgr ws use <workspace>
```

Чтобы выполнить одну команду в другом воркспейсе, не переключаясь, добавьте к ней `--ws <workspace>`.

Это показывает активную задачу и время, учтённое за сегодня:

```sh
tmgr status
```

## Интерактивное меню {#menu}

Не хотите запоминать команды? Наберите `tmgr` без аргументов. Откроется меню, команды в нём сгруппированы слева.

- Стрелки перемещают по группам и командам. Enter или стрелка вправо открывает группу.
- `/` открывает поиск по командам: введите часть названия, например `add`, и нажмите Enter.
- Команда открывается в виде формы. Заполните поля (между ними переходят стрелками или Tab) и нажмите Enter, чтобы запустить команду. Команды, которые меняют что-то важное, сначала показывают экран проверки, и запускает их второе нажатие Enter.
- Esc возвращает назад, `?` показывает подсказку, `q` закрывает меню.

Меню работает только в терминале и не открывается внутри сессии агента.
