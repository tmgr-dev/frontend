`tmgr run` запускает агента и создаёт сессию. Это руководство — о том, что делать с сессией дальше. Первый запуск описан в уроке [AI-агенты под присмотром](/docs/ru/cli/ai-agents-under-supervision). О процессе, который стоит за сессиями, читайте в [Обслуживании раннера](/docs/ru/cli/runner). Общий обзор — в [руководстве по командной строке](/docs/ru/cli#runner).

Все эти команды экспериментальные. Везде, где команда принимает сессию, можно указать её id или имя.

## Посмотреть сессии {#list}

Чтобы вывести сессии вместе с состоянием:

```sh
tmgr agents
```

В каждой строке — имя, состояние, id, команда и папка. Состояние бывает `starting`, `working`, `waiting` (агент ждёт вас), `blocked` (ему нужно решение), `exited` или `failed`. Под таблицей — итоговая строка со счётчиками.

Чтобы вывести то, что сессия показывает прямо сейчас, простым текстом (с `--lines` — больше истории):

```sh
tmgr peek <session> --lines 100
```

Чтобы открыть живой полноэкранный вид; без указания сессии берётся самая новая из запущенных:

```sh
tmgr attach
```

## Переименовать сессию {#rename}

Id не меняется. Новое имя должно быть уникальным среди ваших сессий.

```sh
tmgr rename <session> review-footer
```

## Написать в сессию {#send}

Чтобы напечатать строку в сессии и нажать Enter:

```sh
tmgr send <session> "Run the tests and fix what fails"
```

С флагом `--no-enter` текст печатается без нажатия Enter. Чтобы дождаться ответа и вывести, что появилось на экране, добавьте `--wait idle` (пока агент снова не начнёт ждать или не окажется заблокирован) или `--wait exit` (пока сессия не завершится). `--timeout` ограничивает ожидание, по умолчанию 10 минут.

```sh
tmgr send <session> "Summarize your changes" --wait idle --timeout 5m
```

При `--wait idle` код выхода равен 8, если агент оказался заблокирован. Это удобно в скриптах. Состояние определяется по экрану, поэтому агент может выглядеть свободным, когда это не так.

## Остановить и удалить сессию {#stop}

`halt` останавливает одну сессию: сначала прерывает агента, а если не помогло — завершает. Остановка раннера этого не делает: когда раннер остановлен, сессии продолжают работать.

```sh
tmgr halt <session>
```

Если агент не останавливается, добавьте `--kill`, чтобы завершить его сразу. Для уже завершившейся сессии `--kill` также останавливает оставшиеся от неё фоновые процессы.

Чтобы удалить завершившуюся сессию:

```sh
tmgr rm <session>
```

Если у сессии была своя копия проекта от `--worktree`, вам предложат удалить и её.

## Запустить завершённую сессию снова {#resume}

`resume` запускает завершённую сессию на месте и продолжает разговор с агентом. Команда показывает, что собирается сделать, и просит подтвердить.

```sh
tmgr resume <session>
```

Она принимает и id разговора с агентом, который запускали не через `tmgr`. Чтобы продолжить в новой сессии, не трогая исходный разговор, добавьте `--fork`. `--mode` задаёт режим разрешений, а `--no-attach` запускает сессию без открытия живого вида.

Если сессии остановила перезагрузка или выход из системы, эта команда покажет их и предложит запустить снова, по одному подтверждению на каждую:

```sh
tmgr agents restore
```

## Найти прошлые разговоры {#find}

Чтобы вывести прошлые сессии — и сессии `tmgr`, и сессии Claude Code и Codex на этой машине:

```sh
tmgr session list --agent claude --limit 20
```

`--agent` принимает `claude` или `codex`. Лимит по умолчанию — 50. Чтобы найти сессии по тому, что в них говорилось, используйте поиск. При первом поиске строится локальный индекс ваших расшифровок. Ничего не покидает ваш компьютер.

```sh
tmgr session list --search "footer layout"
```

## Сводка и экспорт расшифровки {#transcripts}

Сводка и экспорт работают только для сессий Claude Code. Для сессий Codex они ответят, что недоступны. Список и поиск охватывают оба агента.

Чтение расшифровок требует вашего согласия. Если оно выключено, команда подскажет, как его включить.

Чтобы вывести короткую сводку того, что сделала сессия:

```sh
tmgr session summary <session>
```

Текст пишет модель. С флагом `--plain` вы получите только файлы, коммиты и пулл-реквесты, и модель не вызывается.

Чтобы сохранить сессию в Markdown-файл или страницей в текущем воркспейсе:

```sh
tmgr session export <session> --md notes.md
tmgr session export <session> --page
```

Перед записью `tmgr` проверяет расшифровку на секреты и даёт вам просмотреть каждую находку. `--remove-findings` убирает их без вопросов. Файл доступен только вам и не перезаписывается без подтверждения. С `--page` текст уходит на сервер TMGR, поэтому для подтверждения нужно ввести код воркспейса. Без `--md` и `--page` ничего не записывается.
