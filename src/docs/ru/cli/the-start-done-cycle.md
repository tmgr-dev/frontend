В этом уроке вы проходите задачу от начала до конца: одна команда в начале работы, одна в конце, а ветка, статус и таймер обновляются сами.

## Текст видео {#transcript}

Урок третий: рабочий цикл. Одна команда в начале работы, одна в конце, а ветка, статус и таймер обновляются сами.

### Старт {#t-start}

Берём задачу: `start` и номер. `tmgr` переводит задачу в статус «в работе», создаёт ветку из номера и названия и запускает таймер.

```sh
tmgr start TM-123
```

Если в рабочей папке есть незакоммиченные изменения, команда остановится, а флаг `--stash` их спрячет.

### Статус {#t-status}

Команда `status` показывает активную задачу и сколько идёт таймер.

```sh
tmgr status
```

Эту же строку можно встроить в приглашение шелла, в tmux или в статус-лайн Claude Code: команда `tmgr init` с названием шелла, например `tmgr init bash`, выдаст готовый сниппет.

### Коммит {#t-commit}

Хук коммитов ставится один раз на репозиторий.

```sh
tmgr git install-hooks
```

Дальше он сам дописывает в каждый коммит строку Refs с номером активной задачи, и коммиты связываются с задачей.

```sh
echo '<p lang="es">Hola</p>' >> index.html
git commit -qam "Add Spanish greeting"
git log -1
```

### Готово {#t-done}

Закончили — команда `done`. Таймер останавливается, время записывается в задачу, а задача уходит на ревью. Если у ветки есть пулл-реквест, ссылка на него добавится в задачу комментарием.

```sh
tmgr done
```

### Итоги дня {#t-today}

А `today` показывает, сколько времени ушло за сегодня и на какие задачи: отдельно ваше время и время агентов.

```sh
tmgr today
```
