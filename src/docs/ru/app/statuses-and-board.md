Статусы и доска входят в модуль Workflow. Включите его в [Настройки → Модули](/settings/modules). Модуль Board работает только вместе с Workflow: если Workflow выключен, у задач вместо статусов флажок **Выполнено**, а доски нет. О пресетах читайте в разделе [модули и пресеты](/docs/ru/web/workspace-modules).

## Статусы {#statuses}

У каждой задачи один статус, а сами статусы принадлежат рабочему пространству. У статуса есть название, цвет и тип. TMGR смотрит на тип; название вы выбираете сами.

Если выключить Workflow, ничего не удаляется. Статусы и их задачи сохранятся и вернутся, когда вы снова включите модуль. Кроме того, TMGR проверяет, что в рабочем пространстве есть статусы, нужные флажку **Выполнено**:

- Нет статуса типа default — добавляется «Backlog».
- Нет статуса типа completed — добавляется «Done». Если есть статус типа active с названием «Completed», вместо этого он становится статусом типа completed.
- Нет статуса типа archived — добавляется «Archived».

## Типы статусов {#types}

- **default**: бэклог. С него начинаются новые задачи. В рабочем пространстве может быть только один такой статус, и удалить его нельзя.
- **active**: работа идёт. Когда вы запускаете таймер на задаче в статусе default, TMGR предлагает перевести её в первый статус типа active.
- **completed**: готовая работа. На доске такие задачи считаются выполненными, а в меню колонки есть действие **Архивировать все**.
- **hidden**: задачи, которые вы хотите отложить. Они остаются на доске в своей колонке, но не попадают в фильтр по статусам в списке.
- **archived**: задачи, с которыми покончено. У них нет колонки на доске, и в списке текущих задач их тоже нет. Открыть их можно на странице «Архив».

Новая задача по умолчанию никогда не попадает в статус hidden или archived.

## Создайте или измените статус {#edit-status}

1. Откройте доску. На широком экране откройте меню ⋮ рядом с кнопкой **Фильтры**. На узком экране вместо этого нажмите кнопку **Фильтры**.
2. Нажмите **Добавить статус**. Форма называется **Создать статус**.
3. Введите название, выберите тип (active, hidden, archived или completed) и цвет.
4. Нажмите **Создать**.

Второй статус типа default в этой форме создать нельзя. Чтобы изменить статус позже, откройте меню его колонки и выберите **Изменить статус**. Поменяйте название, тип или цвет и нажмите **Сохранить**. Статус типа default в рабочем пространстве может быть только один: при попытке сделать второй вы увидите ошибку "Workspace already has a default status".

Чтобы удалить статус, откройте **Изменить статус** и нажмите **Удалить**. TMGR спросит «Вы уверены?». Задачи из этого статуса перейдут в статус default. Сам статус default удалить нельзя.

## Доска {#board}

Каждый статус — это колонка, кроме архивных. Доска работает как канбан: перетащите карточку за её ручку в другую колонку, чтобы сменить статус, или вверх-вниз внутри колонки, чтобы поменять порядок. В меню карточки есть ещё **В начало** и **В конец**.

Элементы вверху сужают доску:

- Кнопка с лупой (**Поиск**) открывает поле для поиска задач по тексту.
- **Фильтры** отбирают задачи по проекту, пользователю, персоне и приоритету. Для фильтров по проекту, пользователю и персоне нужны модули Projects, Assignees и Personas.
- **Сортировать по приоритету** в меню **Фильтры** ставит задачи с самым высоким приоритетом в начало каждой колонки. Пока сортировка включена, порядок внутри колонки вручную не меняется, а **В начало** и **В конец** ничего не делают.
- **Сбросить фильтры** (крестик) очищает все фильтры.

В меню колонки есть пункты:

- **Создать задачу**: новая задача сразу с этим статусом.
- **Изменить статус**.
- **Переместить все задачи в…**: после подтверждения переносит все задачи колонки в другой статус. Пункт виден, только если в колонке есть задачи.
- **Архивировать все**: только у колонок completed (см. ниже).

В каждой колонке есть строка **Добавить задачу**: введите название и добавьте задачу прямо там.

## Порядок колонок {#reorder}

На широком экране откройте меню ⋮ рядом с кнопкой **Фильтры** и включите **Изменить порядок статусов**. В заголовках колонок появятся ручки. Перетащите колонку на новое место.

На узком экране нажмите **Фильтры** и выберите **Изменить порядок статусов**. Перетащите строки в окне **Порядок статусов** и нажмите **Сохранить порядок**.

## Архив {#archive}

Чтобы архивировать целую колонку готовых задач, откройте меню колонки completed и выберите **Архивировать все**. TMGR попросит подтвердить и перенесёт все её задачи в архивный статус. Если в рабочем пространстве нет архивного статуса, вы увидите «Статус архива не найден»: сначала создайте статус типа archived.

Чтобы архивировать одну задачу, выберите **Архивировать** в меню её карточки на доске и подтвердите в окне **Архивировать задачу**. Можно и просто перевести задачу в архивный статус.

Архивные задачи пропадают с доски и из списка текущих задач. Найти их можно в пункте **Архив** меню аккаунта. Чтобы вернуть задачу, смените ей статус на любой другой.
