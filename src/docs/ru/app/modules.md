Модуль — это часть TMGR, которую рабочее пространство может включить или выключить, например доска, страницы или ИИ-ассистент. Модули настраиваются для каждого рабочего пространства отдельно, в [Настройки → Модули](/settings/modules). В заголовке страницы указано, какое рабочее пространство вы меняете. Короткий видеообзор — в уроке [Модули воркспейса](/docs/ru/web/workspace-modules).

Названия модулей приходят с сервера и на любом языке приложения остаются английскими.

## Кто может менять модули {#who}

- Владелец рабочего пространства включает и выключает модули переключателем в каждой строке. Это меняет рабочее пространство для всех его участников.
- Любой участник, включая владельца, может нажать **Скрыть для меня** у модуля. Модуль пропадёт только у вас, а в строке появится **Скрыто для вас**. **Показать для меня** возвращает его.
- Участник, который не владелец, видит «Включать и отключать модули может только владелец рабочего пространства. Для себя модуль можно скрыть.» У выключенного модуля написано «Попросите владельца включить это».

Выключение модуля ничего не удаляет. «Выключение модуля скрывает его для всех в этом рабочем пространстве. Ваши данные сохраняются. Включите модуль снова, и всё окажется на своих местах.»

Если страница относится к выключенному модулю, на ней написано «Этот модуль выключен.» Владелец видит ссылку, чтобы включить модуль, а участнику предлагают попросить владельца.

В каждой строке указаны приложения, в которых работает модуль: web, mobile и desktop. Если модулю нужен другой модуль, строка об этом говорит, например «требуется: Pages».

## Наборы {#presets}

Набор включает сразу несколько модулей. Нажмите **Применить набор** (это может только владелец) и выберите один:

| Набор | Что он включает |
| --- | --- |
| Personal | Dashboard, Checkpoints, Attachments & files, Pomodoro, Reports & export, Routines, Push notifications, Email notifications. Без Workflow: у задач появляется флажок «Выполнено». |
| Team | Dashboard, Workflow, Checkpoints, Attachments & files, Relations, Routines, Reports & export, GitHub, Telegram bot, Import, Push notifications, Email notifications. |
| Developer with AI agents | Dashboard, Workflow, Checkpoints, Attachments & files, AI assistant, Agent work, Personas, Cursor agents, GitHub, Push notifications, Email notifications. |
| Everything | Все модули. |
| Minimal | Никаких модулей, только основное: список, таймер и комментарии. |

Набор также выключает модули рабочего пространства, которых в нём нет. Перед подтверждением окно показывает, что **Будет включено:** и что **Будет отключено:**. Нажмите **Подтвердить**, чтобы применить набор. Модули из блока **Этот аккаунт** набор не меняет.

Когда владелец впервые открывает новое рабочее пространство, TMGR спрашивает «Для чего вам нужен TMGR?». Выберите набор или **Выберу сам**, чтобы отметить модули по одному. **Не сейчас** пропускает вопрос.

В локальном рабочем пространстве приложения для компьютера наборы включают только модули, которые работают без аккаунта, а набора Team нет.

## Основное {#core}

Основные разделы включены всегда. Любой участник может скрыть их для себя в блоке **Скрыть для меня основные разделы**.

| Модуль | Что добавляет |
| --- | --- |
| Projects | Категории с номерами задач вида TM-12: **Категории** в боковой панели, выбор категории и фильтр по категории. См. [Категории](/docs/ru/app/categories). |
| Board | Доску задач. Нужен Workflow: без него доска скрыта. |
| Timer | Таймер запуска и остановки в любой задаче. |
| Comments | Комментарии и реакции в задачах. |
| Assignees | Назначение задач участникам. |

| Модуль | Что добавляет | По умолчанию |
| --- | --- | --- |
| Workflow | Свои статусы, выбор статуса и колонки доски. | Включён |
| Checkpoints | Чек-лист внутри задачи. | Включён |

## Этот аккаунт {#account}

Эти модули принадлежат вам, а не рабочему пространству. «Действует для вас во всех рабочих пространствах.» Каждый пользователь включает и выключает их для себя.

| Модуль | Что добавляет | По умолчанию |
| --- | --- | --- |
| MCP & API tokens | Позволяет Claude Code, Codex и другим агентам работать с TMGR. | Включён |
| Agent alerts & alarms | Агенты могут присылать вам push и звонить. Без него не работает раздел [Настройки → Оповещения агентов](/settings/agent-notifications). | Включён |
| More from the maker | Другие приложения автора TMGR в разделах «О приложении» и «Что нового». | Включён |

См. [Уведомления и оповещения от агентов](/docs/ru/app/notifications#agent-alerts).

## Другие настройки на этой странице {#other}

Под модулями на странице есть несколько настроек, которые от них зависят:

- **Личные предпочтения** — настройки только для вашего аккаунта. **Default Landing Page** выбирает страницу, которая открывается первой при входе: List, Board, Dashboard или Daily Routines. Страница доступна для выбора, только пока включён её модуль; для Board нужен ещё и Workflow.
- **Персоны** — каким персонам можно работать в этом рабочем пространстве. Нужен модуль Personas. См. [Персоны в рабочем пространстве](/docs/ru/app/agent-work#policy).
- **Работа агентов** — **Разрешить моим агентам выполнять мои задачи**. См. [Подтвердить задачи для запусков агентов](/docs/ru/app/agent-work#confirm).
- **ИИ-ассистент** — **Режим записи**, его задаёт владелец. См. [Режим записи](/docs/ru/app/ai-assistant#write-mode).
- **Страницы** — **Персона-аналитик для страниц**, персона, которая ведёт раздел «Инсайты» на страницах людей. Нужны модули Pages и Personas, менять настройку может только владелец.
