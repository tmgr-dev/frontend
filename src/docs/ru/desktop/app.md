TMGR Desktop — приложение TMGR для macOS, Windows и Linux. Оно умеет всё, что веб-приложение, и добавляет таймер в строке меню или системном трее, быстрое добавление из любого приложения, локальные рабочие пространства без аккаунта и плагины.

## Скачать {#download}

Скачайте приложение из [последнего релиза на GitHub](https://github.com/tmgr-dev/frontend/releases/latest). Выберите файл для своей системы:

| Система | Файл |
| --- | --- |
| macOS 13.3 или новее, Apple Silicon | `.dmg` |
| Windows x64 | `-setup.exe` или `.msi` |
| Linux x64 или ARM64 | `.deb`, `.rpm` или `.AppImage` |

Установщик для Windows пока не подписан. Если при первом запуске Windows SmartScreen показывает предупреждение, выберите «Подробнее», затем «Выполнить в любом случае».

## Войти или работать локально {#sign-in}

Если при первом запуске приложение не открыло демо (см. ниже), вы видите экран **Добро пожаловать в TMGR** с двумя кнопками:

- **Начать без аккаунта** создаёт локальное рабочее пространство на этом компьютере. Введите **Ваше имя**, если хотите (это необязательно), и нажмите **Продолжить**. На сервер ничего не отправляется. См. [Локальные рабочие пространства и резервные копии](/docs/ru/desktop/local-workspaces).
- **Войти** открывает страницу входа. Вход через соцсеть открывает браузер, а потом возвращает вас в приложение.

Аккаунт можно создать позже кнопкой **Создать аккаунт** на боковой панели. После входа локальные рабочие пространства остаются на этом компьютере, рядом с облачными. У локальных есть метка **Локальное**.

## Демо {#demo}

Когда вы впервые открываете приложение на компьютере, оно создаёт ваше рабочее пространство «My workspace» и отдельное демо-пространство и открывает демо. В демо симулированный агент чинит баг: карточка движется, таймер идёт, запуск агента заполняется. На вашем компьютере ничего не запускается.

В демо есть баннер с кнопкой **Удалить демо**. Нажмите её и подтвердите. Для демо не делаются резервные копии, его нельзя перенести в облако, и агенты не могут к нему подключиться.

Если вы уже работаете в приложении без аккаунта, оно может один раз предложить демо: **Хотите быстрый тур на примере данных?** Нажмите **Смотреть демо** или **Нет, спасибо**.

## Обновления {#updates}

Приложение проверяет обновления вскоре после запуска и затем каждые 6 часов. Новую версию оно скачивает в фоне. Когда обновление готово, в строке состояния внизу окна появляется кнопка **Обновить до v…**. Нажмите её, чтобы установить обновление и перезапустить приложение.

Чтобы проверить прямо сейчас:

- В macOS выберите File → «Проверить обновления…» в строке меню.
- В Windows и Linux выберите «Проверить обновления…» в меню трея.

Если есть новая версия, нажмите **Установить и перезапустить**.

После обновления открывается окно **Что нового** с примечаниями к новой версии. Чтобы открыть его снова, нажмите номер версии (v…) в строке состояния. У некоторых примечаний есть кнопка **Пройти тур: …**, которая показывает новую функцию.

## Трей и строка меню {#tray}

Если закрыть главное окно, TMGR продолжает работать. В macOS он остаётся в строке меню, и там виден запущенный таймер: прошедшее время и задача. В Windows и Linux он остаётся в системном трее.

Нажмите на значок, чтобы открыть меню:

- Каждая запущенная задача, под ней «Остановить таймер». Нажмите на задачу, чтобы открыть её.
- «Переключиться на» и ваши недавние задачи. Нажмите на задачу, чтобы перевести таймер на неё.
- «Открыть TMGR» показывает главное окно.
- «Решения (N)» открывает окно «Решения», в macOS и Linux. См. [Входящие решения](/docs/ru/cli/the-decisions-inbox).
- «Не беспокоить», см. ниже.
- «Быстрые клавиши…» открывает настройки сочетаний клавиш.
- «Запускать при входе» запускает TMGR, когда вы входите в систему.
- «Проверить обновления…», в Windows и Linux.
- Пункты, которые добавляют плагины, каждый под именем плагина.
- «Выйти из TMGR».

### Не беспокоить {#dnd}

Режим «Не беспокоить» отключает системные уведомления TMGR и его плагинов. В меню трея откройте «Не беспокоить» и выберите «На 1 час», «На 3 часа» или «До завтра» (до 9:00). «Выкл.» выключает режим.

Если вы вошли в аккаунт, то же самое делает колокольчик в строке состояния. Его подсказка — **Не беспокоить**, а пока режим включён, колокольчик перечёркнут.

## Окна задач и страниц {#windows}

У задачи или страницы может быть своё окно:

- В открытой задаче нажмите кнопку-значок **Открыть в отдельном окне**.
- На странице нажмите **Открыть в окне**.

Окно синхронизировано с главным. Если у задачи уже есть своё окно, при повторном открытии задачи это окно выходит на передний план.

## Ссылки tmgr:// {#links}

TMGR Desktop открывает ссылки `tmgr://` из других приложений:

- `tmgr://task/<workspace>/<id>` открывает задачу. Такую ссылку копирует пункт **Копировать ссылку на приложение** в меню **Поделиться** у задачи.
- `tmgr://page/<workspace>/<slug>` открывает страницу. В меню **Поделиться** у страницы тоже есть **Копировать ссылку на приложение**.
- `tmgr://open?path=/<workspace>/board` открывает экран приложения: список, доску, дашборд, страницы, задачу и другие.
- Ссылки `tmgr://plugin/…` принадлежат плагинам. Прежде чем такая ссылка запустит команду плагина, приложение спрашивает: **Разрешить один раз** или **Всегда**.

Ссылка на задачу на `https://tmgr.dev`, по которой вы нажали внутри приложения, тоже открывается в приложении.

В веб-приложении меню **Поделиться** на странице задачи или на странице есть пункт **Открыть в приложении TMGR**.

### Панель «Открыть в TMGR Desktop» {#open-in-desktop}

В веб-приложении на Mac вверху может появиться панель «Вы используете TMGR Desktop.». Она видна, когда вы вошли в аккаунт и за последние 30 дней пользовались десктопным приложением под этим же аккаунтом. Нажмите **Открыть в TMGR Desktop**, чтобы открыть тот же экран в приложении. Панель закрывается крестиком и не появляется до следующего входа.

## Виджет для macOS {#widget}

В macOS можно добавить виджет TMGR на рабочий стол или в Центр уведомлений. Нажмите правой кнопкой на рабочий стол или откройте Центр уведомлений, выберите «Изменить виджеты» и найдите TMGR. Виджет называется «Timer», он бывает маленьким и средним.

Он показывает запущенную задачу с идущим временем, «+N more», если таймеров несколько, или «No timer running». Запустить или остановить таймер из виджета нельзя. Доступа к сети у виджета нет.

## Использование ИИ {#ai-usage}

Страница [Использование ИИ](/ai-usage) показывает, сколько используют и стоят ваши ИИ-инструменты для кода. Откройте её пунктом **Использование ИИ** в группе **Инструменты** на боковой панели. Страница есть только в десктопном приложении.

TMGR читает журналы сессий, которые Claude Code и Codex пишут на этом компьютере. На странице видны токены и стоимость за период, ваши **Лимиты**, таблица **По инструментам и моделям** и **Задачи**: использование, привязанное к вашим задачам по запускам агентов и git-веткам. Стоимость указана в пересчёте на API (по прайс-листу), а не по счёту за подписку. Хранятся только последние 90 дней.

Для лимитов Claude Code нужен хук его строки состояния. См. [Сколько стоит ИИ](/docs/ru/cli/what-ai-costs-you).

### Разрешение читать журналы {#usage-consent}

В первый раз страница спрашивает **Читать журналы ИИ-инструментов?**. Отметьте Claude Code, Codex или оба и нажмите **Разрешить**. **Не сейчас** оставляет чтение выключенным.

Для использования ИИ TMGR хранит количество токенов, стоимость, названия моделей, временные метки, id сессий, папки проектов и git-ветки, названия инструментов, навыков и команд, которые использовал ИИ, типы изменённых им файлов и открытые им pull request'ы. Написанное вами или ИИ он никогда не сохраняет. Ничто не покидает этот компьютер, если вы не настроили выгрузку командой `tmgr usage sync`.

Ваш выбор действует также на фоновые задачи, уведомления агентов, CLI tmgr и раннер TMGR на этом компьютере. Когда чтение включено, раннер читает запущенные им сессии: сохраняет найденные в них вопросы вместе с вашим промптом и ответом на этом компьютере и может отправлять текст ответа в Claude (Haiku), чтобы находить вопросы. Чтобы изменить выбор, откройте [Настройки → Конфиденциальность](/settings?tab=privacy) и найдите раздел **Использование ИИ**:

- **Читать журналы ИИ-инструментов** включает или выключает чтение.
- **Забыть собранные данные** удаляет то, что TMGR хранит на этом компьютере, включая сохранённые раннером вопросы, и выключает чтение. Выгрузки тоже выключаются; уже выгруженное не удаляется. Журналы самих ИИ-инструментов не затрагиваются.
