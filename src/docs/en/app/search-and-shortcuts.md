The command palette finds a task, a page or a place in the app from one search box. Keyboard shortcuts save clicks in the places you use most.

## The command palette {#palette}

Open the palette in one of these ways:

- Press **Search…** at the top of the sidebar. On a narrow screen, press the magnifier in the header.
- Press ⌘K on a Mac or Ctrl+K on Windows and Linux. The same keys close it.

The palette works in the main window of the web app and the desktop app. It is not in a task or page opened in its own window.

With an empty search box, the palette shows:

- **Recent**: the last tasks and pages you opened from the palette, up to 8. They are kept in this browser.
- **Navigation**: the main places of the app, like **Dashboard**, **List**, **Board**, **Pages**, **Files**, **Map**, **Statistics** and **Settings**. A place shows only while its module is on.
- **Workspaces**: your other workspaces. Choose one to switch to it.

Type to search. The palette then shows **Tasks** and **Pages** that match, up to 10 of each, and the places and workspaces whose name matches. Tasks and pages need at least 2 characters. **Pages** shows only while the Pages module is on.

Keys inside the palette:

- ↑ and ↓ move between results. Enter opens the selected one.
- ⌘Enter or Ctrl+Enter, or ⌘-click or Ctrl-click, opens a task or page in a new browser tab. In the desktop app it opens in its own window.
- Esc closes the palette.

If nothing matches, you see "Nothing found".

## Keyboard shortcuts {#shortcuts}

On a Mac use ⌘ (Cmd) and ⌥ (Option). On Windows and Linux use Ctrl and Alt. The app has no list of shortcuts of its own, so they are collected here.

### Anywhere in the app {#global}

| Keys | What it does |
|---|---|
| ⌘K / Ctrl+K | Open or close the command palette |
| ⌘1 … ⌘9 / Ctrl+1 … Ctrl+9 | Switch to the first to ninth workspace, in the order of the workspace switcher |
| ⌘⌥← / ⌘⌥→, Ctrl+Alt+← / Ctrl+Alt+→ | Switch to the previous or next workspace |
| ⌘B / Ctrl+B | Show or hide the sidebar |
| Esc | Close the open task panel or dialog |

When you switch workspaces with the keys, you stay in the same section, for example on the Board.

### Back and forward {#back-forward}

In the desktop app, move through the screens you visited:

- On a Mac: ⌘[ goes back and ⌘] goes forward.
- On Windows and Linux: Alt+← goes back and Alt+→ goes forward.
- The back and forward buttons of a mouse work too, and so do the **Back** and **Forward** arrows at the top of the window.

These keys do nothing while you type in a field. In a browser, use the browser's own back and forward.

### Tasks {#tasks}

| Keys | What it does |
|---|---|
| ⌘S / Ctrl+S | Create a new task, or save the open one |
| Esc while you edit the description | Cancel the edit and bring the old text back |
| Enter in a comment | Send the comment |
| Shift+Enter in a comment | Start a new line |

In the attachment viewer, ← and → go to the previous and next file. For an image, + zooms in, − zooms out and 0 fits it to the window.

### Pages {#pages}

| Keys | What it does |
|---|---|
| ⌘S / Ctrl+S | Save the page now |
| `/` in the editor | Insert a block |
| `@` or `[[` in the editor | Link a task, a page or a member (`[[` links pages only) |

In the link picker, ↑ and ↓ move, Enter or Tab inserts, and Esc closes it. More about pages: [Pages and the map](/docs/app/pages).

### List and Board {#list-board}

- On the List, ↓ and ↑ move between tasks and Enter opens the selected one. In tasks selection mode, Esc leaves it.
- On the Board, in the quick add field of a column, Enter creates the task and Esc cancels.

### Routines {#routines}

On the [Daily routines](/routines) page:

- `N` opens a new routine.
- `/` jumps to the quick add line. Enter adds the routine, Esc clears the line.

`N` and `/` do nothing while you type in a field. More about routines: [Routines in detail](/docs/app/routines).

### Dashboard {#dashboard}

On the dashboard, ⌘R or Ctrl+R reloads the dashboard data instead of the whole page.

### These docs {#docs}

On the docs pages, press `/` to search the docs.

## Desktop shortcuts {#desktop}

The desktop app also has global shortcuts that work when tmgr is in the background: quick add, the timer and screenshot capture. They are described in [Capture and time](/docs/desktop/capture-and-time).
