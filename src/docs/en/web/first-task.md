This lesson walks through one task from start to finish in the web app: create it, track your time, comment and close it on the board.

## Video transcript {#transcript}

TMGR in the browser, lesson one: your first task. Create it, track your time, and close it on the board.

### New task {#t-create}

New task is the button in the header. Type a title, set the priority and project, add a description, and click Create.

Descriptions support Markdown: lists, code, links, and images. The task gets the project key and a number right away, so it is easy to find and to mention in a commit.

### Timer {#t-timer}

The timer button tracks your time. The task is still in the backlog, so TMGR offers to move it to In progress. Accept, and the status changes while the timer runs.

Click again to stop it, and the time is logged to the task.

### Comment {#t-comment}

Comments record what is done. Your teammates see them, and so do the AI agents working on this task.

### Board {#t-board}

On the board, every column is a status. Drag the card to Completed, and the task is done. The columns follow the statuses of your workspace, and you can add your own.
