## Desktop app {#desktop-app}

The desktop app adds a menu-bar timer, quick add and global shortcuts, local workspaces that work without an account, and plugins. Start with [the desktop app](/docs/desktop/app), then read about [quick add, shortcuts and time](/docs/desktop/capture-and-time), [local workspaces and backups](/docs/desktop/local-workspaces) and [plugins](/docs/desktop/plugins).

## AI agents {#ai-agents}

Connect Claude Code, Codex, Cursor and other MCP clients to TMGR. Your agents can work with your tasks and reach you on your phone when they need you. Start with the [AI agents guide](/docs/agents). The [MCP server](/docs/mcp) page lists every tool and every kind of token.

## Command line {#command-line}

`tmgr` lets you work with tasks from the terminal and run AI coding agents where you can watch them, stop them and undo what they did. The [command line guide](/docs/cli) shows what it can do, one scenario at a time.
